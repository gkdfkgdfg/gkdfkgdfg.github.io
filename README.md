# Viper Royale — статическая версия

Игра запускается прямо в браузере. GitHub Pages раздаёт HTML, JavaScript и картинки; отдельный Node.js, Python или VPS для игры не нужен.

**Играть:** https://gkdfkgdfg.github.io/

## Как устроено

- `arena-worker.js` — физика арены, боты, еда, ускорение, турниры и выход с выигрышем. Расчёт идёт в Web Worker браузера.
- `static-runtime.js` — локальный транспорт между игрой и симуляцией. Настоящий WebSocket не открывается.
- `static-storage.js` — настройки в localStorage, свои фоны и скины в IndexedDB. Они сохраняются только в текущем браузере.
- `index.html`, `menu.js` — лобби и настройки.
- `play/index.html`, `assets/` — игровой клиент и графика.

Три режима: практика, обычная игра и турнир. Каждый посетитель играет в собственной арене против ботов. Общего состояния и сетевого мультиплеера между посетителями нет. Валюта и баланс — локальные игровые значения.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
После изменения файлов дождитесь успешной сборки Pages. Репозиторий называется `gkdfkgdfg.github.io`, поэтому ресурсы доступны из корня сайта.

Загруженные пользователем изображения не попадают в GitHub и не передаются другим пользователям. При очистке данных браузера локальные настройки и изображения удаляются.

## Проверено

- Три режима в мобильном размере экрана, движение игрока и ботов.
- Баланс и ставка, локальное сохранение настроек.
- Загрузка и сохранение своего фона и скина после перезагрузки.
- DIN/BTC/SOL/USDT без автоматического `$`; введённый вручную `$` стоит перед числом.
- Запуск без сетевых WebSocket-соединений и без запросов к игровому бэкенду.
